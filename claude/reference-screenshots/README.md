# Reference screenshots

Real lendvue.com screenshots the site owner captured directly from the live site, used as
ground truth for the fidelity passes. `homepage-reference.png` is titled after the live
site's browser tab text (service list), not literally "homepage" — it IS the homepage.

These are useful starting points, but for pixel-exact fidelity work prefer live
measurements from the real site's DOM (see `HANDOFF-FOR-NEXT-SESSION.md` in the project
root) over eyeballing these images — that's the technique that actually worked for the
homepage pass.
